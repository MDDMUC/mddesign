# Content to Design Brief
Connects content strategy requirements to visual design system

## Purpose
This document provides the Design Agent with specific content requirements that must be accommodated in the visual design system. Use this alongside `design-system/BRIEF.md` to create page comps that serve both aesthetic and strategic goals.

---

## Page-by-Page Content Requirements

### Homepage

**Above the fold (Hero Section):**
- Headline: ~40 characters ("Strategic design partner for ambitious companies")
- Subhead: ~150 characters (two lines max)
- Primary CTA button: "View Selected Work"
- Secondary CTA: "Start a Conversation"

**Proof Section:**
- "25+ International Design Awards" headline
- 4-6 award badges (German Brand Award Gold, D&AD, Adobe, Private Equity Wire)
- 6-8 client logos in a single row (BMW, Red Bull, CEPRES, Olympic, Peak Performance, etc.)

**Services Preview:**
- 3 service cards
- Each card: Icon/visual + Title (2-3 words) + Description (25-40 words)
- Services: Strategic Leadership, Product Design, Brand Systems

**Selected Work:**
- 4 featured projects in grid (2x2 or 1 column on mobile)
- Each project card:
  - Project thumbnail image
  - Client logo (small)
  - Project title
  - One-line description (50 characters max)
  - Key outcome or metric (e.g., "6 awards, $45T in assets")

**About Teaser:**
- Profile photo (portrait)
- Short paragraph (100 words)
- "More about me" CTA link

**Contact CTA:**
- Headline: "Let's talk about your challenge"
- Subhead: ~100 characters
- CTA: "Schedule a call" button

**Content density:**
- Homepage should feel spacious and confident
- Prioritize whitespace over cramming information
- Matrix aesthetic: minimal text, maximum impact

## Typography Hierarchy Requirements

Based on Zion aesthetic (minimal, technical, precise):

### Heading Levels Needed

**H1 (Page title):**
- Homepage hero: "Strategic design partner for ambitious companies"
- About: "About Martin"
- Services: "Services"
- Contact: "Let's talk"
- Usage: Once per page, large, primary attention

**H2 (Section headings):**
- "25+ International Design Awards"
- "Context", "Approach", "Results"
- "Experience", "Awards & Recognition"
- Usage: 3-6 times per page, clear hierarchy

**H3 (Subsection headings):**
- Service names: "Strategic Leadership", "Product Design"
- Project titles in work grid
- Usage: Multiple per page, smaller than H2 but distinct

**Body Text:**
- Standard paragraph text (16-18px equivalent)
- Should be readable, not tiny
- Grey (matching stroke colors), not pure black

**Small/Microcopy:**
- Metrics, labels, captions
- Uppercase, increased tracking, very small
- Technical/monospace feel

**Emphasis:**
- Pull quotes (slightly larger, maybe italic)
- Key metrics (large display type)
- CTAs (button text)

### Spacing Requirements
- Generous line-height (1.6-1.8 for body text)
- Large margins between sections (80-120px equivalent)
- Paragraph spacing (1.5-2em)
- Heading to body spacing (0.5-1em)

## Interactive Elements

### Navigation
- Logo/wordmark (top left)
- Main nav items: Work, About, Services, Contact
- Mobile: Hamburger menu (technical, minimal icon)

### Buttons (CTAs)
- Primary: "View Selected Work", "Schedule a call", "Send message"
- Secondary: "Start a conversation", "More about me"
- States: Default, Hover (invert), Active, Focus (for a11y)
- Size: Comfortable click target (44x44px minimum)

### Project Cards (Work grid)
- Hover state: Reveal more info or subtle highlight
- Click: Navigate to case study
- Image aspect ratio: Consistent across all cards

### Form Inputs
- Text fields: Name, Email, Company, Message
- States: Default, Focus, Error, Success
- Labels: Clear and visible (not placeholder-only)
- Error messages: Inline, helpful

### Links
- Inline text links: Subtle underline or different color
- Hover: Animated underline or color change
- Focus: Clear focus indicator

## Content Constraints for Aesthetic

### Keep Text Minimal
- Avoid long paragraphs on homepage
- Use "show, don't tell" with visuals when possible
- Callout boxes for key information instead of prose

### Technical Voice Matches Visual
- Content is confident and direct
- No flowery language or excessive warmth
- Precision in word choice matches precision in design

### White Space is Content
- Don't fill every inch with text or images
- Large margins are part of the experience
- Empty space communicates confidence and quality

### Data Over Decoration
- When possible, show metrics and outcomes
- Use diagrams and charts (minimal, blueprint style)
- Awards and logos as social proof

---

## Visual Content Assets

### Photography Style (when used)
- High contrast, clean backgrounds
- Professional but not corporate-stiff
- Black and white or desaturated preferred (match monochrome palette)
- Avoid busy backgrounds that compete with UI linework

### Project Screenshots/Mockups
- High resolution (2x for retina)
- Clean framing
- Context where helpful (device frames, browser chrome) but not required
- Consistent presentation across all projects

### Logos (Client, Award, Partner)
- Monochrome versions preferred (match stroke grey)
- Consistent sizing and spacing
- Subtle, not competing with content

### Diagrams and Process Visuals
- Match Zion aesthetic: thin lines, technical/blueprint style
- High contrast (grey on white or white on grey)
- Clear and simple, not cluttered

### Icons
- Thin line icons (1-2px stroke)
- Geometric, technical feel
- Consistent style across all icons
- Reserved for navigation and UI, not decorative

## Responsive Considerations

### Mobile (320-768px)
- Stack sections vertically
- Reduce image sizes but maintain quality
- Simplify navigation (hamburger menu)
- Maintain generous spacing (don't cram on mobile)
- CTA buttons full-width or nearly full-width

### Tablet (769-1024px)
- 2-column layouts where appropriate
- Larger images and text
- Side-by-side content and images

### Desktop (1025px+)
- Full layout with maximum whitespace
- Large hero images
- Multi-column grids for project cards
- Floating panels and overlays (Zion aesthetic)

### Content Priority
- On mobile, lead with most important content first
- Hide less critical elements on small screens
- Ensure CTAs are always visible and accessible

---

## Accessibility Requirements (Content-Specific)

### Text Alternatives
- All images need alt text (especially in case studies)
- Icon-only buttons need labels (visible on focus or ARIA)

### Heading Structure
- Proper semantic heading hierarchy (H1 → H2 → H3)
- No skipped levels
- Meaningful headings that describe content

### Link Text
- Descriptive link text ("View CEPRES case study" not "Click here")
- Avoid "Read more" without context

### Color Contrast
- Text must meet WCAG AA (4.5:1 for body, 3:1 for large text)
- Grey text on white background should still be readable
- Test all text/background combinations

### Forms
- Clear labels for all fields
- Error messages that are specific and helpful
- Success confirmation after form submission

### Keyboard Navigation
- All interactive elements must be keyboard accessible
- Logical tab order
- Visible focus indicators

## Summary for Design Agent

**What you're designing:**
A portfolio website for Martin Drexler, an award-winning strategic design partner targeting high-end freelance clients (funded startups and enterprises).

**Content strategy:**
- Position Martin as strategic business partner, not just execution
- Lead with business outcomes and proof (awards, acquisitions, growth)
- Target audience: CEOs, CPOs, CMOs who need strategic + execution
- Premium positioning: $200-300/hr, $20-40K/month retainers

**Visual direction:**
- Zion Virtual Control (Matrix Reloaded) aesthetic
- Monochrome, clinical, precise, blueprint-like
- Large negative space, thin linework, technical feel
- No neon, no color, no heavy decoration

**Key pages:**
1. Homepage: Immediate clarity on who Martin helps and how
2. CEPRES case study: Complex enterprise product transformation
3. YCA case study: Strategic program built from scratch
4. About: Build trust and credibility
5. Services: Clarify engagement models
6. Contact: Make it easy to start conversation

**Success criteria:**
- Visitor understands value proposition in <5 seconds
- Clear differentiation from other designers/agencies
- Confidence and premium positioning communicated visually
- 60fps performance even with Matrix aesthetic
- Fully accessible (WCAG AA)

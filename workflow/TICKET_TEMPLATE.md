# Ticket Template

Use the file-based templates in `tickets/templates/`.

Quick start
1. Copy a template (base.md, epic.md, story.md, task.md, bug.md, spike.md).
2. Rename it to `tickets/<type>/TKT-0001-short-title.md`.
3. Fill in the fields and update `tickets/INDEX.md`.
4. Move the status field as the work advances.
